# Hydropower Sector Memory

> Shared truths and cautions that both pilot symbols inherit.
> Keep this file sector-level only.

## Structural Drivers

- Nepal listed hydropower names are strongly shaped by **project-level physical reality**
- weather matters, but **extreme flood damage** is different from normal monsoon benefit
- policy matters: PPA structure, take-and-pay debates, financing rules, NEA payment health
- seasonality matters: the current lab has a **credible Nov→Jan hydro calendar trade** that is still awaiting forward validation

## Current Lab Learnings That Matter Here

- `L-009`: hydropower has a strong stock-level seasonal calendar
- `L-010`: the strongest current hydro seasonal framing is the Nov→Jan calendar window, not the original "agent fights the calendar" story
- flood damage lane is **not validated yet**, but the `UPPER` sanity check kept it alive in narrower form

## Flood-Lane Rules

1. Use **first credible named public damage report** as the event anchor
2. Prefer **single-project** hydros for treatment and clean controls
3. Compare damaged names to **undamaged hydro peers**
4. Do not confuse:
   - flood warning
   - rainfall event
   - named asset damage

Only the third one is the true company-level event anchor

## Shared Risks

- market-wide panic can swamp company-specific damage
- illiquidity can distort small-name moves
- retrospective narratives can exaggerate how obvious an event was in real time
- hydropower names can share sector moves that look stock-specific if peers are not checked

## Shared Decision Discipline

No symbol-level memo should claim:

- strong buy
- strong avoid
- or sell urgency

unless the memo names:

- the current driver
- the invalidation condition
- the horizon

Otherwise it is not a real decision memo.
