# Experiment 07 — Hydropower Broker-Flow Pattern Lab

> Status: active clean experiment.
> This lane is separate from the live prediction lane and the persistence shadow lane.

## Core Question

When hydropower broker-flow patterns appear, what tends to happen over the next
1, 3, 5, and 10 trading sessions?

The experiment starts from the current UPPER question, but it is not an
UPPER-only opinion lane. UPPER is the case study; peers are the control.

## What This Uses

- Raw Merolagani floorsheet captures:
  - `market-gist/broker_flow_ledger/raw_merolagani/<SYMBOL>/<YYYY-MM-DD>.json`
- Local Sharesansar daily price archive:
  - `sharesansar_datascrape/data/*.csv`

## What This Does Not Touch

- It does not modify live prediction prompts.
- It does not update the persistence shadow policy.
- It does not require the global broker-flow fact table to be fresh.

The builder reads raw inputs directly and writes only inside this folder.

## Controlled Peer Backfill

Use this helper to fill missing broker-flow days in bounded tranches:

```powershell
python .\experiments\07-hydro-broker-flow\backfill_peer_history.py --start-date 2026-03-24 --end-date 2026-04-24 --dry-run
python .\experiments\07-hydro-broker-flow\backfill_peer_history.py --start-date 2026-03-24 --end-date 2026-04-24 --max-dates 5
```

The helper uses the collection-only broker-flow scraper and skips symbol-dates
that already exist. Dry-runs label existing data as `ledger`, `raw`, or
`raw_empty`; empty raw checks are excluded from broker-flow pattern counts by
the dataset builder. It writes raw ledgers to the shared broker-flow data store,
but does not touch live prediction or shadow-policy files.
